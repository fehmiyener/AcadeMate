# AcadeMate

#TR

Eğitim almak isteyen kullanıcıları uzmanlarla buluşturan ve yorumlara erişim sağlayan ücretsiz bir web platformu. Node.js, HTML, CSS, JavaScript ve MySQL kullanılarak geliştirildi. Xampp üzerinde çalıştırıldı ve proje sürecinde ekip çalışması deneyimi kazandım.

#EN

A free web platform connecting learners with experts and providing access to reviews. Developed using Node.js, HTML, CSS, JavaScript, and MySQL, and deployed on Xampp. Gained hands-on experience in teamwork during the project.
